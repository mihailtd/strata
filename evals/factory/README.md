# Factory adapter evaluation

Task/quality evaluation of trained adapters — as distinct from `benchmarks/factory/`'s geometry/training-perf measurement of the training pipeline itself.

- [`duckdb_eval/`](duckdb_eval/) — DuckDB domain adapter evaluation.
- [`eval_instrument/`](eval_instrument/) — expert-vs-base diagnostic instrument.
- [`agentic/`](agentic/) — held-out/task-quality evaluation of agentic adapter behavior (see its own README).

See [`evals/README.md`](../README.md) and the repo's [`docs/METHODOLOGY.md`](../../docs/METHODOLOGY.md).
